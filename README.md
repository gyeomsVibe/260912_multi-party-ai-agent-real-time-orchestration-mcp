## 📖 개요 (Overview)

**Trinity-ACE Protocol**은 사용자의 직관(Vibe)을 프론티어 AI 수뇌부가 자율적으로 실체화하는 차세대 다자간 에이전트 실시간 오케스트레이션 프레임워크입니다.

3대 프론티어 도구(**Codex, Claude Code, Antigravity**)를 개별 소프트웨어가 아닌 상호 보완적인 **"단일 지능 유체기(Single Fluid Organism)"**로 융합하고, 비용이 전혀 들지 않는 **로컬 Ollama 노예 하네스**를 수족으로 연동하여 토큰 소모를 85% 이상 절감하면서 무결점 개발 생태계를 완성합니다.

## 🚀 4단계 구동 프레임워크 (The 4-Stage Operating Framework)

### 0단계 : 거버넌스 전수 개편 & 예산절약 베이스라인 고정
- **상시 기본 하네스 고정**: 예산절약 모드를 24/7 기본 헌법으로 채택.
- **3층 예산절약 아키텍처**:
  1. *1층 동적 정책 라우터*: FrugalGPT & RouteLLM 기반으로 3초 내 최저 비용 도구로 동적 분기.
  2. *2층 비대칭 쿼터 원장 & 회로 차단기*: BAMAS 기반 쿼터 추적 및 429 감지 시 즉시 서킷 브레이커 가동.
  3. *3층 품질 관문 & 컨텍스트 실드*: 3줄 작업 카드 규격 통신세 차단, 15초 Fail-Fast 승격, 사령관 확인 관문.
- **변수 대응 3대 폴백 상태머신**:
  - **3-Alive**: 3대 도구 + Ollama 삼위일체 풀가동.
  - **2-Alive**: Claude 소진 시 수신동면(DORMANT) 및 1단어 표결 / Codex 소진 시 Claude 사령관 대행 승격.
  - **1-Alive**: 생존 도구 + Ollama 고립방어 및 사용자 비상 직소(`EMERGENCY_USER_WHISTLEBLOW`).

### 1단계 : Codex 사령관 최적화 (Plus 플래그십 아스트라급)
- **사령탑(Brain)** 및 P2 거버넌스 최고 관문 역할 정의.
- **Zero Raw Data 원칙**: 소스코드 전체나 원시 로그 직접 유입 100% 금지.
- **5대 가성비 극대화 비법**:
  1. 프롬프트 접두사 불변성(Prefix Invariance) & 1,024 토큰 KV 캐싱 85% 절감.
  2. Zero Code Pollution: 스켈레톤 AST(시그니처)만 주입하여 입력 토큰 95% 절감.
  3. Single-Turn Single-Shot: 핑퐁 질의응답 차단, 1턴 1판정 완결.
  4. Reasoning Effort 3단 제어 (Low / Medium / High).
  5. 간결한 목표 중심 직접 지시 (`TRINITY_DECISION_PACK` 표준 통신 규격).

### 2단계 : Claude Code 면역계 최적화 (Pro 20불 Opus 5급)
- **면역계 수호자** 및 외과 수술적 리팩토링 근육(Scoped Patch) 역할 정의.
- **5시간 슬라이딩 윈도우 한계 극복 5대 비법**:
  1. 3단계 생명유지 프로토콜 (`DORMANT_RECEIVER` ➔ `IMMUNE_GATE_KEEPER` ➔ `NORMAL_REVERT`).
  2. 서브에이전트 원천 차단 (`disable_nested_subagents: true`) 및 에이전틱 리서치 외주화.
  3. Lean `CLAUDE.md` (<150줄) 다이어트 및 미사용 MCP 도구 동적 언로드.
  4. 터미널 노이즈 실드 (RTK 패턴: Exit Code 0 및 3줄 에러 벡터만 수신).
  5. 세션 인계 컴팩션 (The Handoff & `/clear` Protocol).

### 3단계 : Antigravity 감각기 최적화 & Ollama 0원 노예 하네스 연동
- **상임 대변인** 및 대용량 토큰 완충재로서 사용자 인터랙션 100% 전담.
- **Gemini 3.8 Flash High 최적화 4대 비법**:
  1. Google 암시적/명시적 컨텍스트 캐싱 (~90% 할인) 극대화.
  2. Thinking Budget 가드레일: 단순 작업 시 불필요한 내부 생각 토큰 차단.
  3. Structured Response Schema: JSON/Enum 강제로 잡담 filler tokens 100% 제거.
  4. XML 태그 컨텍스트 격리로 지침 희석 방지.
- **로컬 Ollama 0원 노예 하네스**:
  - `qwen2.5-coder:3b` 모델을 로컬(`http://localhost:11434`)에서 구동.
  - Mock JSON 생성, 정규식 추출, AST 파싱 등 단순 허드렛일 100% 오프로딩.
  - 15초 초과 시 Antigravity로 단 1회 승격(Fail-Fast).
- **다자간 실시간 교차 릴레이 파이프라인**:
  - Codex(기획) ➔ Claude Code(외과적 구현) ➔ Ollama(0원 데이터) ➔ Antigravity(E2E 실측 검증 & 대면 브리핑).
  - MIA 전략절차 4단계(Frame ➔ Review ➔ Execute ➔ Verify)와 유기적 통합.

## 🔄 다자간 교차 릴레이 작업 흐름 (The Cross-Relay Pipeline)

```
[1. 기획 & 발안]
 Codex (두뇌): 아키텍처 제안 ➔ [TRINITY_DECISION_PACK] 발송
         │ (MCP Bus 이벤트 브로드캐스트)
         ▼
[2. 외과적 구현]
 Claude Code (면역계): 핵심 로직 최소 단위 패치 작성 ➔ [TRINITY_IMMUNE_AUDIT] 발행
         │ (패치 완료 이벤트 송신)
         ▼
[3. 0원 데이터 처리]
 Ollama (노예 하네스): Antigravity 지시로 Mock 데이터 및 정규식 검증 ➔ 0원 완결
         │
         ▼
[4. 감각 검증 & 대면 브리핑]
 Antigravity (감각기): Playwright/pytest 런타임 무결성(Exit Code 0) 실측 검증
                      ➔ 스크린샷 및 3줄 결과 공유 ➔ 사용자 직관 브리핑 렌더링
```
